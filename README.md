# Модель управленческих компетенций в здравоохранении

Проект объединяет модель управленческих компетенций и приложение для её экспертной проверки. Текущий этап на 7 октября 2026 года — подготовка пилота экспертной оценки с назначением двух блоков на участника.

- [Смысл проекта и текущий этап](PROJECT.md).
- [Приложение экспертной оценки и запуск](expert-review/README.md).

Полная рабочая редакция содержания от 24 сентября 2026 года: 8 блоков, 24 компетенции.

Открыть [полный HTML-отчёт](competency-model-report.html): все блоки расположены последовательно, слева закреплено оглавление, в начале есть карта модели и пояснение уровней, в конце — таблица границ между блоками. Все стили и сценарии встроены; сервер для просмотра не нужен. Содержание доступно без JavaScript. Montserrat загружается из Google Fonts; без сети используется системный шрифт.

[Модель с переключением блоков](competency-model.html) также обновлена из того же источника.

## Файлы и редактирование

- `model-content.json` — единый источник содержания и статусов.
- [model-content.md](model-content.md) — текстовая версия всей модели для просмотра, генерируется из JSON.
- `competency-model-report.html` — основной отчёт для общего просмотра; все 24 компетенции видны последовательно, без переключения вкладок.
- `competency-model.html` — общая модель с переключением блоков, внутренними ссылками и печатью всех восьми блоков.
- `block-N-competencies.html` — отдельная страница блока с переходами к соседним блокам и общей модели.
- `templates/` — оформление и навигация; сохраняют принятый эталон HTML-отчётов.
- `tools/render_model.py` — сборка стандартными средствами Python, без дополнительных пакетов.

После изменения содержания или шаблонов:

```bash
python3 tools/render_model.py
```

Ссылки в блоках 4–8 — методические ориентиры. Формулировки компетенций разработаны для этого проекта; источники не являются готовой моделью из 24 компетенций.
